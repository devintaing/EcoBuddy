# EcoBuddy

EcoBuddy is a web-based ecological AI assistant built by [Arthur Roth](https://github.com/yeemans), [Pari Sharma](https://github.com/sharma-pari), [Ryan Tran](https://github.com/rytgo), and [Devin Taing](https://github.com/devintaing).

Technologies Used: Firebase, React, Tailwind, JavaScript, HTML, CSS.
