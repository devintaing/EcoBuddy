# 🌿 EcoBuddy

EcoBuddy is a web-based ecological AI assistant built by [Arthur Roth](https://github.com/yeemans), [Pari Sharma](https://github.com/sharma-pari), [Ryan Tran](https://github.com/rytgo), and [Devin Taing](https://github.com/devintaing).

Technologies Used: Firebase, React, Tailwind, JavaScript, HTML, CSS.

## Main Features
### 🤖 AI-Powered Image Analysis
- Uses Gemini to identify whether an item is recyclable or compostable
- Provides detailed disposal instructions

### 🛍️ Eco-Friendly Product Alternative Suggestions
- Recommends sustainable alternatives to common household items
- Helps users switch to greener products

### 📊 Action Log
- Allows users to determine how much carbon emissions their eco-friendly actions are saving
- Displays previous eco-friendly actions, product suggestions, and image analysis

### 🌐 Social Features
- Streak counter to encourage habit building
- Leaderboard to compare points against other users

### 👤 User Authentication & Onboarding
- Secure login/sign-up using Firebase Authentication
- User-generated data is linked to each account
